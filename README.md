# Metabolomics and density functional theory guide infrared recognition of herbivory and defense responses in tea plants

This private repository provides access to the original available data files associated with the study.

## Download

Download `Data_upload_package_20261113.zip` from the repository **Releases** page. The archive contains the original data exports and descriptive sample metadata. No analysis code, processed matrices or mean spectra are included.

## Contents

| Data | Files |
| --- | --- |
| Metabolomics | Three original Excel workbooks containing platform abundance exports, annotations and sample information |
| ATR spectra | 432 original spectral CSV exports |
| DFT calculations | 1980 original Gaussian GJF inputs and 839 normally terminated LOG outputs |
| Metadata | Sample identifiers, EG/SA/JA groups, treatment times, molecular file indices and data descriptions |

EG denotes *Ectropis grisescens* feeding, SA denotes salicylic acid treatment and JA denotes jasmonic acid treatment. Metadata distinguishes the manuscript subset from additional available files.

Metabolomics workbooks contain the available platform relative peak area exports, rather than instrument acquisition files. Original spectral CSV files contain wavenumber and measured ATR intensity pairs. Original Gaussian files retain their original contents. Checkpoint files are excluded.

The archive includes Chinese and English data descriptions, a data dictionary, a file inventory and integrity checksums. Original data file contents were preserved during collection.
